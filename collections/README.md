# Postman Collections

本目录存放 Postman 集合文件，用于 API 契约测试。

## 集合文件

| 文件名 | 描述 | SoT 对应 |
|--------|------|----------|
| ai-ad-api-collection.json | 主 API 集合 | API_SOT.md v9.0 |
| auth-collection.json | 认证 API 集合 | AUTH_SPEC.md v2.0 |
| daily-reports-collection.json | 日报 API 集合 | STATE_MACHINE.md v2.6 |

## 创建集合

1. 在 Postman 中创建集合
2. 添加测试脚本验证响应
3. 导出为 JSON 格式
4. 保存到本目录

## 基准文档

- AUTOMATION_TEST_SPEC_v1.4.md 第 6 章
- API_SOT.md v9.0
