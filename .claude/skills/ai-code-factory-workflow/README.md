# AI 代码工厂工作流 Skill

> **版本**: v5.1  
> **状态**: ✅ 生产就绪  
> **更新日期**: 2026-01-09

## 概述

这是一个可以在 **Claude/Cursor 对话框中直接用自然语言调用** 的 AI 代码工厂工作流执行器。

## 快速开始

### 在 Claude/Cursor 中使用

直接在对话框中输入自然语言需求，例如：

```
创建一个用户管理功能，包括列表、创建、编辑、删除
```

```
审查用户管理模块的代码质量
```

```
修复用户登录功能的 bug
```

```
优化用户列表查询性能
```

```
设计微服务架构方案
```

## 支持的工作流

### 1. 全栈功能开发

**触发词**: "创建"、"开发"、"实现"、"做一个"

**示例**:
- "创建一个用户管理功能"
- "开发一个订单系统"
- "实现日报审核功能"

### 2. 代码审查

**触发词**: "审查"、"检查"、"review"

**示例**:
- "审查用户管理模块的代码质量"
- "检查这段代码的安全性"

### 3. Bug 修复

**触发词**: "修复"、"bug"、"问题"

**示例**:
- "修复用户登录功能的 bug"
- "解决日报审核的问题"

### 4. 性能优化

**触发词**: "优化"、"性能"、"慢"

**示例**:
- "优化用户列表查询性能"
- "提升日报加载速度"

### 5. 系统架构

**触发词**: "架构"、"设计"

**示例**:
- "设计微服务架构方案"
- "系统架构设计"

## 使用示例

### 示例 1: 创建功能

**输入**:
```
创建一个用户管理功能，包括：
1. 后端 API：列表（分页、搜索）、创建、编辑、删除
2. 前端页面：用户列表、创建表单、编辑表单
3. 数据验证：用户名唯一、邮箱格式
4. 权限控制：只有管理员可以删除
```

**输出**:
- 系统架构设计
- 后端 API 代码
- 前端页面代码
- 代码审查结果
- 测试代码

### 示例 2: 代码审查

**输入**:
```
审查用户管理模块的代码质量和安全性
```

**输出**:
- 代码质量审查报告
- 安全审计报告
- 性能分析报告
