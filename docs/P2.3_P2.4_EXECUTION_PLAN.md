    data: Any = None,
    message: str = "操作成功",
    code: int = 200,

**修改后代码**:
```python
def error_response(
    message: str = "操作失败",
    code: int = 400,
    data: Any = None,
    timestamp: str = None,
    request_id: str = None,  # ✅ 新增参数
    error_code: str = None  # ✅ 新增参数（错误码标识符）
) -> Dict[str, Any]:
    """
    错误响应格式

    Args:
        message: 错误消息
        code: 错误状态码（HTTP 状态码，兼容旧版）
        data: 错误详情数据
        timestamp: 时间戳
        request_id: 请求唯一标识符  # ✅ 新增说明
        error_code: 错误码标识符（如 "AUTH_401"）  # ✅ 新增说明

    Returns:
        Dict: 标准错误响应格式
    """
    from datetime import datetime

    # ✅ 自动生成 request_id（如果未提供）
    if request_id is None:
        request_id = generate_request_id()

    response = {
        "success": False,
        "message": message,
        "data": data,
        "code": code,  # HTTP 状态码（兼容旧版）
        "request_id": request_id,  # ✅ 新增字段
        "timestamp": timestamp or datetime.now().isoformat()
    }

    # ✅ 如果提供了 error_code，添加到响应中
    if error_code:
        response["error_code"] = error_code

    logger.error(f"API响应错误: {message} [request_id={request_id}] [error_code={error_code or 'N/A'}]")  # ✅ 日志记录
    return response
```

**风险点**:
- 🟡 **向后兼容性**: 新增字段，不影响现有调用
- 🟢 **error_code 可选**: 未提供时不添加该字段，避免前端解析错误

**自检点**:
- [ ] `request_id` 和 `error_code` 参数默认值为 `None`
- [ ] 自动生成 `request_id` 逻辑正确
- [ ] `error_code` 仅在提供时添加到响应

## 📝 附录：ERROR_CODES.md 错误码参考

| 错误码 | HTTP 状态码 | 错误信息 | 使用场景 |
|--------|------------|----------|----------|
| `AUTH_400` | 401 | 未提供认证令牌 | 请求头缺少 Authorization |
| `AUTH_401` | 401 | 无效的认证令牌 | Token 验证失败 |
| `AUTH_402` | 401 | 令牌已过期 | Token 过期 |
| `AUTH_002` | 403 | 账户已被禁用 | is_active = False |
| `AUTH_500` | 403 | 权限不足 | 角色权限不足 |
| `AUTH_004` | 404 | 用户不存在或已被禁用 | 用户查询失败 |
| `SYS_001` | 500 | 系统内部错误 | 未捕获的异常 |
| `ROLE_001` | 404 | 角色记录未找到 | 角色分配/移除时记录不存在 |

**注**: P2.3/P2.4 阶段 `error_code` 为可选字段，P2.5 阶段将统一所有错误码。
