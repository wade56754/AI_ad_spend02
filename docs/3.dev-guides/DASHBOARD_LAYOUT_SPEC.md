# 老板驾驶舱页面布局规格

> **版本**: v1.0
> **基准**: A1-dashboard.md v1.0, MASTER.md v4.4 §6.5, PROJECT.md v1.3
> **更新日期**: 2025-12-25

---

## 1. 页面目标

**一句话定义**: 让老板在 5 秒内掌握"今天公司怎么样"

| 老板问题 | 系统答案 | 对应区域 |
|---------|---------|---------|
| 今天花了多少钱？ | 今日消耗 KPI | KPI 卡片区 |
| 今天进了多少粉？ | 今日粉数 KPI | KPI 卡片区 |
| 整体 CPL 怎么样？ | CPL 指标 + 趋势图 | KPI 卡片区 + 趋势区 |
| 预计今天赚还是亏？ | 预计毛利 KPI | KPI 卡片区 |
| 哪些项目需要关注？ | 异常项目数 + Top 列表 | 状态卡片区 + 归因区 |
| 有什么待处理？ | 待审批充值数 | 待处理区 |

## 3. 组件规格

### 3.1 StatCard (KPI 卡片)

```typescript
interface StatCardProps {
  title: string;           // 标题: "本月总消耗"
  value: string;           // 主值: "¥285.7万"
  change: number;          // 变化率: 12.5 (百分比)
  changeType: 'up' | 'down' | 'neutral';
  subtitle?: string;       // 副标题: "今日 ¥12.6k"
  target?: string;         // 目标值: "目标 ¥35.00"
  icon?: ReactNode;        // 图标
  color?: 'blue' | 'green' | 'red' | 'orange';
  onClick?: () => void;    // 点击联动趋势图
  isActive?: boolean;      // 是否选中状态
}
```

**视觉规格**:

| 属性 | Desktop | Tablet | Mobile |
|------|---------|--------|--------|
| 宽度 | 280px | 48% | 100% |
| 高度 | 140px | 120px | 100px |
| 圆角 | 12px | 12px | 8px |
| 内边距 | 20px | 16px | 12px |
| 标题字号 | 14px | 12px | 12px |
| 主值字号 | 28px | 24px | 20px |
| 变化率字号 | 14px | 12px | 12px |

**颜色规则**:
- 正向变化 (↑): `text-green-500`
- 负向变化 (↓): `text-red-500`
- 无变化 (→): `text-gray-500`
- CPL 下降是好事，用绿色

### 3.2 StatusCard (状态卡片)

interface StatusCardProps {

## 4. 交互规则

### 4.1 KPI 卡片联动

| 交互 | 触发 | 行为 |
|------|------|------|
| 点击 StatCard | 单击 | 趋势图切换到对应指标 |
| StatCard 选中 | 点击后 | 卡片显示 `ring-2 ring-blue-500` 边框 |
| 切换时间范围 | 下拉选择 | 全部 KPI + 趋势图 + Top 列表同步刷新 |

### 4.2 跳转规则

| 点击元素 | 跳转目标 | URL 参数 |
|---------|---------|---------|
| 待审批充值 | /topups | `?status=pending` |
| 异常项目数 | /projects | `?filter=abnormal` |
| Top 列表项 | /projects/:id | - |
| 活跃项目 | /projects | `?status=active` |
| 待结算项目 | /settlements | `?status=pending` |

### 4.3 刷新策略

| 数据类型 | 刷新频率 | 实现方式 |
|---------|---------|---------|
| KPI 卡片 | 页面加载 + 手动刷新 | `useQuery` |
| 趋势图 | 时间范围变化时 | `useQuery` + 依赖 |
| Top 列表 | 页面加载 | `useQuery` |
| 待处理数 | 5 分钟轮询 | `useQuery` + refetchInterval |

## 5. 数据字段映射

### 5.1 KPI 卡片数据 (MASTER.md §6.5)

| 字段 | 来源表 | 计算公式 | 边界处理 |
|------|--------|---------|---------|
| 本月总消耗 | ad_spend_daily | `SUM(spend)` | - |
| 本月总进粉 | daily_report | `SUM(conversions)` | - |
| 整体 CPL | 计算 | `总消耗 / 总进粉` | 0 粉显示 "--" |
| 预计毛利 | 计算 | `收入 - 成本` | 无单价显示 "待定" |
| 活跃项目数 | project | `COUNT(status='active')` | - |
| 异常项目数 | 计算 | `CPL > target × 1.3` | - |
| 待审批充值 | topup_request | `COUNT(status='pending')` | - |

### 5.2 CPL 边界场景 (MASTER.md §4.5.2)

```typescript
function formatCPL(spend: number, conversions: number): string {
  if (conversions === 0) {
    return "--";  // 零转化
  }
  if (conversions < 5) {
    return `¥${(spend / conversions).toFixed(2)} (低量)`;
  }
  return `¥${(spend / conversions).toFixed(2)}`;
}
```

### 5.3 金额格式化

```typescript
function formatAmount(amount: number): string {
  if (amount >= 10000) {
    return `¥${(amount / 10000).toFixed(1)}万`;
  }
  if (amount >= 1000) {
    return `¥${(amount / 1000).toFixed(1)}k`;
  }
  return `¥${amount.toFixed(2)}`;
}
```

### 6.2 数据范围过滤

```typescript
function getDataScope(role: string, userId: number) {
  switch (role) {
    case 'ceo':
    case 'finance':
    case 'admin':
      return { scope: 'all' };
    case 'project_owner':
      return { scope: 'owned_projects', ownerId: userId };
    case 'supervisor':
      return { scope: 'team', supervisorId: userId };
    case 'pitcher':
      return { scope: 'self', pitcherId: userId };
    default:
      return { scope: 'none' };
  }
}
```
