## 3. 消耗日报逻辑

### 3.1 日报字段

| 字段 | 说明 | 计算方式 |
|------|------|----------|
| `date` | 消耗日期 | - |
| `today_max` | 转点截图Today MAX | 从平台截图读取 |
| `yesterday_max` | 转点截图Yesterday MAX | 前一日数据 |
| `actual_spend` | 实际消耗 | `today_max - yesterday_max` |
| `fee` | 手续费 | `actual_spend × fee_rate` |
| `total_spend` | 包含手续费的消耗 | `actual_spend + fee` |
| `notes` | 备注 | 异常情况说明 |

### 3.2 消耗计算公式

```
实际消耗 = 今日截图值 - 昨日截图值
手续费 = 实际消耗 × 手续费率 (根据代理商和账户类型)
总消耗 = 实际消耗 + 手续费
```

### 3.3 手续费率规则

不同代理商和账户类型有不同的手续费率：

| 代理商类型 | 手续费率 | 说明 |
|-----------|---------|------|
| 三不限 | 10% | 如 B哥-fb三不限10➕1 |
| 二不限 | 7-10% | 如 十月二不限 |
| 官方授权户 | 0-5% | 费率较低 |
| 普通代理 | 7-11% | 根据账户类型浮动 |

## 5. 数据导入逻辑

### 5.1 Excel 导入格式

| 列 | 字段 | 必填 | 说明 |
|----|------|------|------|
| A | 日期 | 是 | 消耗日期 |
| B | 地区 | 是 | 投放地区 |
| C | 投手 | 是 | 投手代码 |
| D | 账户名称/ID | 是 | 账户名称 + 平台ID |
| E | 账户种类 | 是 | 账户类型 |
| F | 代理商 | 是 | 代理商名称 |
| G | 平台 | 是 | FB/TK |
| H | 转点截图Today MAX | 是 | 今日截图值 |
| I | 转点截图yesterday MAX | 否 | 昨日截图值 |
| J | 备注 | 否 | 备注信息 |
| K | 手续费 | 自动 | 系统计算 |
| L | 实际消耗 | 自动 | 系统计算 |
| M | 包含手续费的消耗 | 自动 | 系统计算 |

### 5.2 导入处理流程

```
1. 解析 Excel 文件
   ↓
2. 验证数据格式
   - 检查必填字段
   - 验证日期格式
   - 验证投手/代理商是否存在
   ↓
3. 自动创建/匹配
   - 新账户自动创建
   - 匹配现有投手/代理商
   - 不存在则报错或自动创建
   ↓
4. 计算消耗数据
   - 实际消耗 = today - yesterday
   - 手续费 = 实际消耗 × 费率
   - 总消耗 = 实际消耗 + 手续费
   ↓
5. 写入数据库
   - 更新账户信息
   - 插入日报记录
   ↓
6. 生成导入报告
   - 成功/失败统计
   - 异常数据列表
```

## 8. 数据库表结构建议

### 8.1 ad_accounts 表更新

```sql
ALTER TABLE ad_accounts ADD COLUMN IF NOT EXISTS
  platform_account_id VARCHAR(50),        -- 平台账户ID
  account_type VARCHAR(50),               -- 账户种类
  region VARCHAR(50),                     -- 投放地区
  fee_rate DECIMAL(5,4) DEFAULT 0.10;     -- 手续费率
```

### 8.2 daily_spend_records 表 (新增)

```sql
CREATE TABLE daily_spend_records (
  id SERIAL PRIMARY KEY,
  ad_account_id BIGINT REFERENCES ad_accounts(id),
  date DATE NOT NULL,
  today_max DECIMAL(15,5),                -- 转点截图Today MAX
  yesterday_max DECIMAL(15,5),            -- 转点截图Yesterday MAX
  actual_spend DECIMAL(15,5),             -- 实际消耗
  fee DECIMAL(15,5),                      -- 手续费
  total_spend DECIMAL(15,5),              -- 包含手续费的消耗
  notes TEXT,                             -- 备注
  created_at TIMESTAMP DEFAULT NOW(),
  created_by UUID REFERENCES users(id),

  UNIQUE(ad_account_id, date)
);
```
