## 二、业务模式

### 模式A：自投项目（主营，95%）

```
公司 → 承担投放风险 → 赚取利润差价
```

| 环节 | 说明 |
|------|------|
| 资金 | 公司自有资金或客户预付款 |
| 执行 | 公司投手操作投放 |
| 风险 | 公司承担，效果不好则亏损 |
| 收益 | 客户付款 - 广告成本 = 毛利 |

**典型项目：** 德国Summer、印度20期、印尼一期

### 模式B：外部代投（少量，5%）

```
客户 → 委托公司投放 → 公司收取服务费
```

| 环节 | 说明 |
|------|------|
| 资金 | 客户提供 |
| 执行 | 公司投手代为操作 |
| 风险 | 客户承担 |
| 收益 | 固定服务费或消耗提成 |

**典型项目：** 岳总

### 3.3 数据对账流程

```
┌──────────────────────────────────────────────────────────────┐
│                     每日对账流程                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│      投手自报                              平台真实           │
│   ┌───────────┐                       ┌───────────┐         │
│   │daily_report│                       │ad_spend   │         │
│   │           │                       │_daily     │         │
│   │ 消耗: X   │                       │ 消耗: Y   │         │
│   │ 进粉: N   │                       │ 手续费: F │         │
│   └─────┬─────┘                       └─────┬─────┘         │
│         │                                   │                │
│         └───────────┬───────────────────────┘                │
│                     ↓                                        │
│              ┌───────────┐                                   │
│              │  对 账    │                                   │
│              ├───────────┤                                   │
│              │ X vs Y    │ → 差异分析                        │
│              │ 以 Y 为准 │ → 确认实际消耗                    │
│              │ Y + F     │ → 计算总成本                      │
│              └───────────┘                                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**对账原则：**
- 消耗金额：以 `ad_spend_daily.actual_spend` 为准
- 手续费：`actual_spend × 代理商费率`
- 总成本：`actual_spend + fee`

## 五、关键业务指标 (KPI)

### 5.1 投手维度

| 指标 | 计算公式 | 说明 |
|------|----------|------|
| 日消耗 | SUM(actual_spend) by date, buyer | 当日广告花费 |
| 进粉数 | SUM(lead_count) | 获取的有效用户 |
| 单粉成本 (CPL) | 消耗 / 进粉数 | 获客效率 |
| 成效数 | SUM(result_count) | 广告平台成效 |

### 5.2 项目维度

| 指标 | 计算公式 | 说明 |
|------|----------|------|
| 总支出 | SUM(spend_with_fee) | 含手续费的成本 |
| 实际收入 | actual_revenue | 客户付款 |
| 毛利 | 收入 - 支出 | 项目盈亏 |
| 毛利率 | 毛利 / 收入 | 盈利能力 |

### 5.3 公司维度

| 指标 | 计算公式 | 说明 |
|------|----------|------|
| 月消耗 | SUM(actual_spend) | 广告总投入 |
| 月收入 | SUM(actual_revenue) | 总收款 |
| 月净利 | 收入 - 所有成本 | 公司利润 |

## 六、当前业务痛点

| 痛点 | 影响 | 建议解决方案 |
|------|------|--------------|
| **代理商费率未结构化** | 手续费计算靠人工 | 建立费率表，系统自动计算 |
| **项目命名不规范** | 统计聚合困难 | 制定命名规则，拆分复合项目 |
| **投手自报≠平台消耗** | 数据真实性存疑 | 强制对账机制，标记差异 |
| **预付款跨项目共享** | 难以追踪余额 | 独立预付款账户，禁止共用 |
| **账户ID格式混乱** | 无法精确匹配 | 统一提取 platform_id |

## 七、MVP 系统建议功能

### 必须有 (P0)

1. **投手日报录入** - 每日消耗/成效/进粉
2. **平台消耗导入** - Excel 导入并自动清洗
3. **对账看板** - 自报 vs 平台差异
4. **项目盈亏表** - 月度毛利统计

### 应该有 (P1)

5. **代理商费率管理** - 维护费率表
6. **账户管理** - 账户-代理商-投手 绑定
7. **投手绩效看板** - 消耗/CPL 排名

### 可以有 (P2)

8. **客户预付款管理** - 余额追踪
9. **自动对账告警** - 差异超阈值提醒
10. **趋势分析** - 历史数据可视化
