> 让 Claude 自己发现问题、修复 skill、验证结果

---

## 使用方法

将以下内容发送给 Claude：

```
请阅读我的 prompt-optimizer skill，然后：
1. 用这个 skill 生成一个"API 测试用例"提示词
2. 对照参考模板，逐项检查生成的提示词
3. 找出 skill 的缺陷
4. 给出具体的修复代码
5. 展示修复后的完整提示词

## Skill 文件

{粘贴 skill 的 SKILL.md 和 rules/ 下的文件}

## 强制自检清单

生成提示词后，必须逐项验证：

### P0 检查（全部通过才能输出）
| # | 检查项 | 验证方法 | ✓/✗ |
|---|--------|----------|-----|
| 1 | 代码块闭合 | 数 ``` 数量是否成对 | |
| 2 | XML 标签闭合 | 每个 <tag> 有 </tag> | |
| 3 | 有 <constraints> | 搜索这个标签 | |
| 4 | 有 <error_handling> | 搜索这个标签 | |
| 5 | 有 <examples> | 示例在独立标签内 | |
| 6 | 无空行表格行 | 表格无 | | | | | | | |

### 验证流程
1. 把生成的提示词完整复制一遍
2. 逐行对照上表检查
3. 发现问题立即修复
4. 全部通过后再输出

⚠️ 禁止：评分表写"已修复"但提示词未修复

## 核心要点

1. **先生成，再检查** - 不要边写边评分
2. **逐项验证** - 用检查清单强制自检
3. **展示证据** - 检查结果必须有 ✓/✗
4. **真正修复** - 给出可复制的代码
5. **二次验证** - 修复后再走一遍检查清单
