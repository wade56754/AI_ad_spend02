## 状态转换规则

| 当前状态 | 可转换到 | 触发条件 | 操作人 |
|---------|---------|---------|-------|
| raw_submitted | trend_pending | 自动 | 系统 |
| trend_pending | trend_ok | 趋势正常 | 系统 |
| trend_pending | trend_flagged | 趋势异常 | 系统 |
| trend_flagged | trend_resolved | 确认正常波动 | project_owner |
| trend_ok | final_pending | 自动/手动 | 系统 |
| trend_resolved | final_pending | 自动/手动 | 系统 |
| final_pending | final_confirmed | 确认最终粉数 | project_owner |
| final_confirmed | final_locked | 月度结算 | 系统 |

## Phase 1 约束

- ❌ **禁止**: `trend_flagged` 时自动拒绝或阻断
- ✅ **允许**: 高亮显示、发送通知、记录日志
