## 第一章 验收概述

### 1.1 验收目标

本文档定义 AI 广告代投系统上线前必须通过的所有验收检查项，确保：

- 功能完整性：所有核心业务功能正常运行
- SoT 合规性：代码实现符合单一真相源定义
- 安全性：认证、授权、数据保护机制完备
- 性能达标：响应时间、并发能力满足基准要求
- 可运维性：监控、告警、回滚机制就绪

### 1.2 本文档不做

本文档不承担以下职责（边界声明）：

- 不定义业务规则（属于 BUSINESS_RULES.md）
- 不定义状态机（属于 STATE_MACHINE.md）
- 不定义 API 接口（属于 API_SOT.md）
- 不定义错误码（属于 ERROR_CODES_SOT.md）
- 不执行测试（仅定义验收标准，执行由团队完成）

### 1.3 验收角色

**验收签字角色**（非系统角色）：

| 验收角色 | 验收职责 | 签字要求 |
|---------|---------|---------|
| 技术负责人 | 功能验收、性能验收 | 必须 |
| 安全负责人 | 安全验收 | 必须 |
| 业务负责人 | 业务规则验收 | 必须 |
| 运维负责人 | 部署验收、监控验收 | 必须 |

**系统角色**（引用 AUTH_SPEC.md v2.0）：

| 系统角色 | 角色代码 | 验收相关职责 |
|---------|---------|------------|
| 系统管理员 | `admin` | 全局验收审批 |
| 财务 | `finance` | 账本/红冲功能验收 |
| 数据运营 | `data_operator` | 日报录入功能验收 |
| 账户管理员 | `account_manager` | 账户管理功能验收 |
| 广告投手 | `media_buyer` | 日报提交功能验收 |
